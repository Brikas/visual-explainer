# visual-explainer (fork)

An agent skill that turns an explanation into one HTML page of figures. This repository is a fork of [nicobailon/visual-explainer](https://github.com/nicobailon/visual-explainer) (MIT).

- **Skill:** [plugins/visual-explainer/SKILL.md](plugins/visual-explainer/SKILL.md)
- **How the fork differs and how to merge upstream:** [plugins/visual-explainer/ADAPTATION.md](plugins/visual-explainer/ADAPTATION.md)
- **Harness:** Claude Code, with the skill folder linked into the agent's skills directory
- **Requires:** Node.js. The render's browser check uses Google Chrome through `playwright-core`.
