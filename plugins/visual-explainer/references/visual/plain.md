# Plain

The default style. It uses the browser's fonts and dark text on white. Dark mode uses light text on near-black. One link-blue accent. It fits any page.

- Shapes are outlines on the page background. They have no fill, shadow, glow or stage grid.
- The accent marks the one key node or hot path. Everything else is text color or dim text color.
- Page CSS only for layout the content needs: a card grid, a file map, two panels side by side.
