# Plain

The default. Browser fonts, dark text on white (light on dark in dark mode), one link-blue accent. Fits any page.

- Shapes are outlines on the page background: no fills, shadows, glows, or stage grid.
- The accent marks the one key node or hot path; everything else is text or dim text.
- Page CSS only for layout the content needs: a card grid, a file map, two panels side by side.
